# LilQ 会計アプリ

個人事業主の日々の記帳、請求書作成、入金確認をまとめるための日本語Webアプリです。React / TypeScript の画面と Express / SQLite のサーバーで構成し、Lenovo PC上のサーバーをデータの正本とする運用を目指しています。

> **開発・検証中です。正式な税務申告にそのまま使用できる完成済み会計製品ではありません。** 過年度申告書との1円単位の照合、税務実務者レビュー、Lenovo本番環境のバックアップ復元試験など、正式運用の受入条件は未完了です。申告内容は必ず原資料・公的情報・税理士等に照らして確認してください。

## 主な機能

- 複式簿記の仕訳登録、複合仕訳、日付順の仕訳帳、試算表・元帳・損益計算書・貸借対照表
- 確定済みの通常仕訳を、元仕訳を残して反対仕訳と訂正仕訳で修正
- 請求書の作成・プレビュー・PDF保存、売掛金の計上、分割入金と入金口座の記録
- 取引先・勘定科目・事業者情報の管理、レシート・証憑の保管
- サーバーモードではSQLiteを使用し、ログイン・CSRF保護・年度締め・監査履歴・暗号化バックアップを提供
- 摘要や過去の登録履歴を使った**確認用**の仕訳候補。候補は自動確定されず、税務判断を代行するものではありません

## 技術スタック

- React、TypeScript、Vite、Tailwind CSS
- Express、Zod、Node.js組み込みSQLite（`node:sqlite`）
- Windows起動タスクとTailscale Serveを使った個人向け配備構成

## 開発環境での起動

Node.jsとpnpmを用意してから実行します。

```sh
pnpm install
pnpm dev
```

品質確認と本番ビルド:

```sh
pnpm check
pnpm test
pnpm build
```

サーバーを起動する場合は `pnpm start` を使用します。サーバーのデータ保存先は `KAIKEI_DATA_DIR` で指定でき、未指定時はOSのProgramDataまたは現在の作業ディレクトリ配下になります。実運用ではアプリ用の専用データディレクトリを指定してください。

## Lenovo（Windows）への配備

このリポジトリにはWindows用の配置スクリプトがあります。詳しい手順、データ保存場所、ヘルスチェック、Tailscale Serve設定は [`deploy/windows/README.md`](deploy/windows/README.md) を参照してください。

- SQLite本体は `%ProgramData%\LilQKaikei` に保存し、Google Drive同期フォルダへ直接置かない
- アプリは `127.0.0.1:4175` で待ち受け、外部からのアクセスはTailscale Serve経由に限定する
- 配備前にSQLiteデータと証憑をバックアップし、更新後に `/api/v1/health`、ログイン、主要画面、バックアップ状態を確認する
- APIキーやパスワードなどの秘密情報をソースコード・Git・公開Issueへ登録しない
